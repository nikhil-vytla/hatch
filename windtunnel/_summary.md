Windtunnel is a working v0 of a deterministic simulation engine for evaluating, training, and stress-testing AI agents — synthesizing ideas from [Snowglobe](https://guardrailsai.com/snowglobe/docs/overview), [Prime Intellect's verifiers](https://github.com/PrimeIntellect-ai/verifiers), Inspect AI, and Petri/Bloom into four abstractions none of them combine: an event-sourced world with per-actor hidden state, a universal actor model (NPCs, adversaries, and chaos daemons are peers of the agent-under-test), discrete-event virtual time with named RNG streams, and contract verification via an LTL-lite algebra whose verdicts cite the exact events that justify them. The determinism boundary is the key design move: the world is a pure function of (spec, seed, decision stream), so nondeterministic LLM actors get recorded and replayed bit-for-bit — tampering with one recorded decision is detected by hash-chain fingerprint. The reference support-desk world demonstrates the full loop: a seeded chaos daemon knocks out a billing tool, the agent retries and recovers, a deliberately leaky agent variant fails exactly the secret-leak invariant with the guilty event id as evidence, and 23 property/e2e tests plus ruff and pyright hold it all green.

- Everything-is-an-actor makes multi-agent and chaos engineering the same mechanism: perturbations are scheduled, seeded, trace-attributed decisions, invisible to actors but visible to omniscient verifiers.
- Worlds compile from briefs + seeds into a hashable declarative IR (TOML/JSON WorldSpec), so even future LLM-generated environments stay auditable and citable as (spec hash, seed, version).
- Population QA works today: `windtunnel run --generate support_desk --seeds 20` yields pass rates with replayable repro traces for every failure.
