Candidate 2 designs an Inspect-style coding session as an append-only event journal with rebuildable UI, agent, sync-gate, child-session, and GitHub projections. A per-session sequencer gives multiplayer prompts deterministic queue order, while at-least-once sandbox and agent subscribers use durable claims and idempotent effect ids for crash recovery. The public API hides [OpenCode](https://opencode.ai/) and infrastructure protocols, and a fake local composition runs without cloud credentials. The shape follows the key constraints in [Ramp's background agent write-up](https://builders.ramp.com/post/why-we-built-our-background-agent), including read-before-sync, write gating, user-authored PRs, resume snapshots, and multi-client streaming.
