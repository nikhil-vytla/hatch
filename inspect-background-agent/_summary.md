One product, built from scratch: an Inspect-style background coding agent with a workspace-grade frontend. The agent runs OpenCode free models in isolated git sandboxes with serial per-session queues, fork/archive lifecycle, multiplayer authorship, webhook ingress, automations, and a push + GitHub-PR flow; the UI (session sidebar, streaming log, Files/Diff tabs, and a per-session sandbox **terminal**) took its interaction bar from [hermes-workspace](https://github.com/outsourc-e/hermes-workspace), including its security model — fail-closed non-loopback bind, auth on every API route, rate-limited login — all test-proven. A Cloudflare + Modal three-plane path (shared compute contract, SessionAgent/EventBus Durable Objects, Modal ASGI app) is verified locally via `npm run e2e:cloud`; inspiration but not a fork of [ColeMurray/background-agents](https://github.com/ColeMurray/background-agents).

- Green without API keys: `npm test` (18), `npm run e2e` (agent turn + commit + destroy + auth gate), `npm run e2e:cloud`, `npm run eval:smoke`
- Browser-verified: streamed turns, artifacts, and `cat src/math.ts` inside the session sandbox terminal
- Needs credentials to light up: real Modal/Cloudflare deploys, GitHub PR-as-user, Slack bot
