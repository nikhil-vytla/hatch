A Lean 4 port of the live kernel for chat-grown software, written in Lean itself: the process holds a Lean `Environment` as the live image, elaborates each accepted form in-process with the frontend and runs it through `evalConst`, with no `lean` subprocess. Its language-specific gate is proof: a change may carry Lean theorems about the app's functions (for example "by_category sums to total"), and the kernel rejects the change if any proof, new or from an earlier turn, fails to check. Money is held as exact `Int` cents with decimal conversion at the JSON boundary so that `omega` and `simp` can prove arithmetic laws. The kernel passes all 51 conformance checks, with develop averaging about 350 ms.

- Showcase: bugs that pass every confirmed example and 300 random property tests (dropping expenses over $1000, `>=` instead of `>` in `over_budget`) are rejected by the failing proof; false or vacuous claimed laws and `sorry`/`native_decide`/`axiom` cheats are rejected too.
- Built on [Lean 4](https://github.com/leanprover/lean4) core only (no Mathlib); non-terminating recursion is caught by the termination checker, not a timeout.
