Neurons vs vectors

A single-neuron push adds one fixed direction to the model’s running state; a steering vector is any direction, and here each one is built by contrasting the model’s replies with and without “You are a {concept}.” Every arm below adds a push of exactly the same size at the same layer, so they compare fairly. “Clean” means a judge says the model became the concept and stayed coherent.
