Evidence

Every number on this site comes from public data. This page shows how to check each claim yourself and which checks were run by someone, or something, other than the people who made the claims. The scripts, the pre-registration, the judge comparison, and the blind human audit are all linked below.

Recompute it yourself

Install three Python packages, then run verify.py from the repository. The claims table gives the value we stated, the value the script recomputes, the 95% interval when one was reported, and the source file for each claim.

pip install duckdb pyarrow huggingface_hub
python verify.py

The chart shows only claims with a reported interval. Each row has its own 0-to-maximum scale because claims use different counts; the hollow ring is the stated value, the filled dot is recomputed, and the line is the 95% interval.

Predictions made before the data

The pre-registration was committed before the results were read. Each prediction below is listed with what was measured; the one that failed is shown first.

A second judge

A second model re-labeled a sample of the same replies without seeing the first judge’s labels. Agreement is the share of items given the same label; Cohen’s κ corrects for agreement that would happen by chance.

The second judge, DeepSeek-V4-Pro, is a different model from the same lab as the first judge (DeepSeek-V4.1-Flash), so this is a partial check rather than an independent one.

Dashed reference lines mark κ = 0.4 (moderate), 0.6 (substantial), and 0.8 (near perfect).

Blind human audit

The blind human audit shows 120 items with the judge’s answers hidden; each rater’s labels are stored separately so one rating cannot overwrite another. Results are scored with audit/score.py in the repository, which compares human labels with the judge and reports agreement and κ.

Open the blind audit

Ratings are kept per rater, so you can run the scoring script on one rater or on all of them.
