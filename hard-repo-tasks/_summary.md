Parallax compiles pinned public or private repositories into deterministic counterfactual coding tasks, with separate public starter and sealed evaluator capsules plus adapters for [HUD](https://hud.ai/) and [Prime Intellect Verifiers](https://github.com/PrimeIntellect-ai/verifiers). Twelve tasks derived from Click rejected no-op, upstream restoration, and unrelated-path tampering, but live calibration showed that the first capture-policy family was not frontier-hard: GPT-5.6 Sol passed all four audited semantic attempts, and three inspected DeepSeek traces also passed every behavioral component. The rollouts exposed a misaligned scope reward that punished agents for adding useful tests, as well as a macOS containment failure that let an agent modify a source clone outside its HUD workspace. The resulting curriculum controller rejects the family and calls for cross-module, sequence-dependent contracts with semantic-mutant validation inside hard container isolation.
