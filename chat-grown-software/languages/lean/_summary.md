A Lean 4 port of the live kernel for chat-grown software, written in Lean itself: the process holds a Lean `Environment` as the live image, elaborates each accepted form in-process with the frontend and runs it through `evalConst`, with no `lean` subprocess. Its language-specific gate is proof: a change may carry Lean theorems about the app's functions (for example "by_category sums to total", or for the second, LLM-gateway scenario "no key's usage ever exceeds its quota"), and the kernel rejects the change if any proof, new or from an earlier turn, fails to check. Money is held as exact integer cents so that `omega` and `simp` can prove arithmetic laws. Both scenarios pass conformance (expenses 51/51, gateway 28/28), with develop averaging about 350 ms.

- Showcase: bugs that pass every confirmed example and 300 random property tests (dropping expenses over $1000, an off-by-one in a quota check, a quota exemption for one key) are rejected by the failing proof.
- Built on [Lean 4](https://github.com/leanprover/lean4) core only (no Mathlib); non-terminating recursion is caught by the termination checker, not a timeout.
