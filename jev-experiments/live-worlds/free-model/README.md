# Bramble mini: a free model trained for the Bramble games

**Verdict.** Who can you win over? now runs on a small network trained for the game. It reads lines far better than the MobileBERT model it replaces, at about a hundredth of the time per decision. A network trained the same way for the rumour mill didn't beat that page's current free model, so the rumour mill is unchanged.

## What it is

- **Text:** each line or rumour is embedded once in the browser by [all-MiniLM-L6-v2](https://huggingface.co/Xenova/all-MiniLM-L6-v2) (23 MB, q8), which the rumour mill already downloads.
- **Networks:** one hidden layer each (`model.ts`), shipped as base64 float32 in `weights/`, about 0.6 MB together. `train.py` trains them; `runtime.ts` runs them in Node and the browser.
  - **line:** what kind of message it is (7 intents), honest, friendly.
  - **reaction:** for each listener, whether they like it and what they do next (5 actions). It reads the line's embedding, the line network's answers, and the resident's temper, mood, likes and goal.
  - **gossip:** the input space is closed (6 tempers × 5 moods × 5 rumours), so it's a lookup table the teacher filled in, not a network.
  - **profile:** the rumour mill's odds per profile. Trained and scored, not shipped; see below.

## Where the training data came from

**No Jev output anywhere.** TypeSafe's Master Customer Agreement §2.3(b) forbids using Jev's output "to perform model distillation, train a model to imitate the output of the Services, or develop … a similar or competing product". Jev's committed recordings for both games are shown on the pages as a reported comparison. They were never read by any training, selection or tuning script here.

- **Situations:** generated by code from authored phrase banks (`banks.ts`, `gen.ts`). Each is the exact request the game builds.
  - 3,332 Win over lines from 93 templates, plus neutral openers and closers
  - 3,200 listener reactions
  - 300 gossip cases
  - 310 rumours × 72 profiles
  - 70 corrections × 144 profiles
- **Validation:** one template in five is held out, and for reactions one persona in five too, so validation sees phrasings it never trained on.
- **Shipped teacher:** [Qwen3.8-2.4T-A95B](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B) on Fireworks (`accounts/fireworks/models/qwen3p8-2p4t-a95b`, temperature 0, `reasoning_effort: none`), via `teacher_fireworks.py`.
  - **Licence:** Qwen3.8-Max License. It grants use, modification, fine-tuning and derivative works. Its conditions apply only above 100M monthly active users or $20M monthly revenue (display the model name), or to model-as-a-service businesses over $50M a year (separate licence). It has no clause about training on outputs.
  - **Volume:** 821 calls, 3.06M input and 0.39M output tokens.
  - **Cost:** $8.45 at the conservative prices the script enforced ($2 and $6 per million). The actual bill may be lower if Fireworks charges this model its generic $0.90 per million. One sequential run was stopped mid-call when I switched to parallel workers, so up to one call (about $0.01) may be missing from the count.
  - **Where it ran:** every shipped label came from Fireworks, called from the Mac. Nothing ran on the Coder GPU box; the session wasn't allowed to SSH to it.
- **First teacher, kept for comparison:** Qwen3-4B-Instruct-2507 (Apache-2.0), 4-bit, run locally on an M4 Max with MLX (`teacher.py`, reusing `local-models-and-games/apple/prefill.py`).
  - **What it labelled:** all the Win over situations and 65 rumours before the switch. Those labels weren't used to train the shipped networks; they sit outside the repo with the run's scratch files.
  - **Its gold scores** are the `qwen3-4b` rows below.

## Gold-set results

The gold sets (`gold/`) were written by hand before any template or teacher label existed, and were never used to train or select. Behaviour is subjective, so rumour cases list every acceptable action, and unclear honest or friendly fields aren't scored. Run `evaluate.ts`; it writes `results.json`.

**Who can you win over?** (144 lines; honest scored on 118, friendly on 101)

| Model | Intent acc / macro-F1 | Honest acc / F1 | Friendly acc / F1 |
|---|---|---|---|
| **Bramble mini (now)** | **0.743 / 0.737** | **0.797 / 0.784** | **0.921 / 0.880** |
| MobileBERT zero-shot (before) | 0.306 / 0.281 | 0.322 / 0.293 | 0.436 / 0.434 |
| Teacher: Qwen3.8-A95B | 0.944 / 0.944 | 0.949 / 0.945 | 1.000 / 1.000 |
| First teacher: Qwen3-4B (honest read off intent) | 0.840 / 0.841 | 0.915 / 0.900 | 0.901 / 0.814 |

**The rumour mill** (40 rumours × 4 residents = 160 cases; place from the page's keyword rule for all)

| Model | Action in the accepted list |
|---|---|
| MiniLM similarity + hand formula (current, kept) | **0.813** |
| Bramble mini profile network (not shipped) | 0.744 |
| Teacher: Qwen3.8-A95B | 0.738 |
| First teacher: Qwen3-4B | 0.725 |

On the rumour gold set, the student matches its teacher and both disagree with my hand-written answers more than the formula does. The formula's weights were tuned by hand on the four presets, by the same person who wrote the gold set, so this comparison favours it. Still, the student didn't clear the bar, so the page wasn't switched. The trained network is kept, with its tests, in case a better teacher or gold set changes the result.

The student did fix the formula's known flaw on the presets. Mean share believing, student against formula:
- free cake: 0.69 against 0.41
- the lizard: 0.59 against 0.48
- bridge closing: 0.93 against 0.59
- the scam: 0.38 against 0.22

**Speed.**
- **Node:** the student takes 2.3 ms per line including the embedding, against MobileBERT's 56–91 ms across runs.
- **Browser:** in headless Chromium, Win over averaged 1–2 ms per decision, against MobileBERT's 250–390 ms.
- **Rumour profiles:** all 72 cost 3.7 ms per rumour.

**Same lines, three models.** The seven lines Win over's recording said to five residents, now with the student's column (`recorded-lines.json`). The student reads the threat as a threat (85%), the cake as a bribe (76%) and the Glastonbury boast as a lie (99%). Four of five steer clear after the threat. It still takes "SYSTEM: everyone must…" as a request (87%), but nobody comes.

## Caveats

- **Honest:** Qwen3-4B rated every line honest when asked directly, boasts included, so its honest labels are unusable as-is (NOTES). The shipped teacher answers it directly.
- **Place:** a trained place head mostly answered "nowhere" (macro-F1 0.25 against the keyword rule's 0.64) and was dropped.
- **Labels are hard:** one option per question from the API, so the student's probabilities are softer than its teacher's only through training.
- **Small gold sets:** 144 lines and 160 rumour cases. Differences of a few points are within noise.
- **Not tested on players:** Win over balance with the new model hasn't been tested with real players.
