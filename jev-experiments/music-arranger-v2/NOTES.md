# Music arranger implementation notes

## 2026-09-20

- Created this folder before starting implementation. Read the Music audit, its proposed simulation, the existing player, gateway, recording tools, and repository instructions.
- The original five completed recordings remain historical evidence. Version 2 is a separate recording set using all eight original briefs and a declared balanced set of six contour requests. It will retain request state, generated candidates, selection distributions, provider attempts, and final scores.
- Implementation uses one explicit score for six tracks, including note/rest spans, onset beats, durations, velocities, track instruments, tonic/mode, actual chord voicings, phrase locks and provenance. The same event list feeds playback, drawing and MIDI.
- No extra package is required. Existing Tone.js and @tonejs/midi cover scheduling and MIDI. Small diatonic chord/voice-leading functions stay readable and directly testable.
- Applied the unslop writing skill. The papercuts skill was triggered by a source-path probe for a nonexistent types.ts. Its logger says this repository has not opted in, so no papercut file was created.
- No listener has evaluated this implementation. Structural validity, timbre differences and complete records cannot establish subjective musical quality.
- Recording exposed a provider HTTP 400 at phrase three in five cases. The gateway accepted these requests locally, but the upstream service rejected the larger repeated-candidate state. No successful decisions were discarded. The corrected request stores the five identical accompaniment tracks once and each candidate's melody separately; those lists reconstruct every exact candidate event. Permanent failures remain in call history, and only the changed request is submitted again. This is a request-format correction, not a quality retry.
- The first nine tests passed, including 45 tonic/mode/progression combinations, all contour families, score locking, bar-boundary adoption, cancellation generations and full six-track MIDI round trips at three tempos and three instrument palettes. MIDI checks compare each pitch, onset, duration, velocity, channel and program.
