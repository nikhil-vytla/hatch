An icon workbench uses Jev to select from 1,703 [Lucide icons](https://lucide.dev/) and previews the result inside navigation, cards and buttons. Six recorded product contexts produced complete two-stage candidate comparisons, with every request and answer retained for replay. The interface adds manual shortlists, styling controls and SVG/React export to the direction explored by [icon-matcher-ui](https://github.com/sandra-arato/icon-matcher-ui). Grouping can affect the winner, and these authored examples have no independent preference labels, so the workbench exposes useful choices without claiming retrieval accuracy.
