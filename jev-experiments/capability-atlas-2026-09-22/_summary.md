An interactive capability atlas traces all 41 local Jev experiments from model input to typed question, code behavior and existing evidence. The audit found that our wrappers block [native structured criteria](https://docs.typesafe.ai/primitives/advanced) and narrow [Score semantics](https://docs.typesafe.ai/primitives/score), with repeatable provider-free probes showing the specific losses. The site integration adds a per-experiment disclosure and checks source fingerprints so outdated explanations are not presented as current. The roadmap now prioritizes preserving the native contract and running controlled comparisons inside existing experiments; new model measurements remain open.
