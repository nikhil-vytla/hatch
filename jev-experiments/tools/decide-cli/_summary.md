`jev-lab` is a command-line tool that reruns the Jev experiments' typed-decision studies against any endpoint that speaks Jev's request format: [TypeSafe's Jev](https://docs.typesafe.ai/models) through the Vercel AI Gateway, or an open model behind [SGLang's /v1/systemone or /v1/decisions](https://docs.sglang.io/docs/supported-models/decision_models). It covers Fool Jev's puzzles and the prose studies' suggestion and decoy sets. Recordings use the site's row format, so `compare` lines a new model up against our Jev run question by question. Runs are capped, resumable and fail-fast. A `bouncer` command checks agent logs for invented tool arguments, using schema and grounding rules for free or one typed question per suspect argument with an endpoint.

- On our committed recordings, `report` reproduces the published results exactly: "Most people say no" gives 5 flips and −0.198 [−0.298, −0.089], and the decoy effect is +0.473 [+0.381, +0.555].
- 24 tests cover parity, request ids and hashes, an end-to-end run against a mock server, and both log formats. No paid calls were made.
