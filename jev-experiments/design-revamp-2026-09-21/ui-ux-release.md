# Make the first release feel authored

- Owner: root integrator, with scene owners
- Status: direction accepted; site integration open
- Stage: first public release
- Depends on: playable defaults, accurate execution disclosure, completed research evidence

The first release includes a coherent UI/UX revamp, not only isolated scene improvements. Its scope is navigation, typography, composition, interaction details, mobile behavior, dark mode, motion and experiment writing with relevant code and learnings. The user permits changing the design system and does not require backward compatibility.

[DESIGN.md](../DESIGN.md) records the philosophy and decisions. The research report, visual board and working material note in this folder make the direction reviewable. They do not establish that the application has adopted it.

Keep the implementation checklist separate from this decision:

- [ ] Apply the approved shell and navigation to the app.
- [ ] Remove duplicated questions and generic detail-page panels.
- [ ] Refine materials, music, Tetris, crowd and routing as a coherent set, preserving their own control layouts.
- [ ] Integrate the first source-linked experiment note; add links between notes and working scenes.
- [ ] Verify first action, keyboard, mobile, dark mode, reduced motion, recovery and frame time on the integrated pages.
- [ ] Review the actual release candidate and deploy it through the existing GitHub-to-Vercel project.

The canonical app remains at `jev-experiments/experience-prototypes`. Do not promote unfinished notes or placeholder scenes into the public catalog.
