Experiment 28 uses 40 prompts sampled from Google's [IFEval dataset](https://github.com/google-research/google-research/blob/4700efb9afa54286b0e04473ba80a13e8461e25f/instruction_following_eval/data/input_data.jsonl) and 20 creative prompts authored for the demo. The IFEval sample uses seed 42, and the first displayed request is case 1601. Qwen3-0.6B generated four responses per request, Jev selected among them, and Gemini 2.5 Flash-Lite supplied a separate reference response. The [published record](https://jev-experiments.vercel.app/data/language.json) confirms this split, which the UI should explain more clearly.
