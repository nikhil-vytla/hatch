The focused correction preserves those descriptions and adds six regression test methods across the two suites, including plain Noul boundaries and default Choice labels. Local toolchain availability prevented a before/after execution, so the new code remains subject to root's exact-archive rerun. The original passing reports, optional Python skip and local-only scope remain unchanged.
