# Parallax decision records

These documents are the direct ancestors of
[`../MODEL.md`](../MODEL.md) and
[`../methods/evolving-intent.md`](../methods/evolving-intent.md). They are
records of decisions already made, preserved with their original substance;
they do not define implemented behavior.

- [`ADR-001.md`](ADR-001.md) — the architecture decision to place one
  immutable research protocol above strategy-specific state machines instead
  of a universal transformation algebra.
- [`DESIGN-SELECTION.md`](DESIGN-SELECTION.md) — the four-candidate
  architecture arena, the cross-judge scorecard, the winning design, and the
  accepted grafts and rejections.
- [`LITERATURE-PINS.md`](LITERATURE-PINS.md) — the primary-source pin table:
  the exact papers, repository revisions, and release records the decisions
  were checked against, with what each source does and does not fix.

The full experimental archive — the formal model, the complete literature
review, the arena candidate files and judge record, the episode-spine and
synthesis-kernel investigations, and all working notes — lives on the
archive branch
[`cursor/hard-repo-tasks-5fc8`](https://github.com/nikhil-vytla/hatch/tree/cursor/hard-repo-tasks-5fc8/hard-repo-tasks),
under `hard-repo-tasks/architecture/`. That branch is an archive of a
superseded experiment, not a merge candidate.
