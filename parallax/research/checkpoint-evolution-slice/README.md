# Checkpoint-evolution executable slice

This investigation implemented checkpoint evolution — the
SlopCodeBench-derived synthesis method designed in
[`../slopcodebench-method/`](../slopcodebench-method/README.md) — as
Parallax's second executable strategy, alongside Evolving Intent. The
deliverable is an offline-verifiable vertical slice: typed domain model,
black-box entrypoint verifier, executable admission gates, a
harness-owned checkpoint runner with two controlled arms, and a
hand-verified seed family that runs end to end with scripted agents. No
paid inference ran in this unit.

The as-implemented contract lives in
[`../../docs/methods/checkpoint-evolution.md`](../../docs/methods/checkpoint-evolution.md);
this folder records how the work got there.

## The invariants that matter

- **Grading gates checkpoint N on 1..N-1**: the strict verdict is the
  conjunction over Ω_N = Ω_{N-1} ∪ T_N; prior-stage cases re-run as
  regression obligations at every later stage. Mutants that drop prior
  obligations (M01) or compute strict from new cases only (M02) die.
- **Harness-owned, unskippable delivery**: the agent is a pure function
  of (public spec, carried workspace, budget) with no advance channel;
  `FamilyRun` validation makes graded episodes with skipped, reordered,
  or drifted checkpoint delivery unrepresentable (M09, M14 die).
- **Workspace fidelity**: the evolved arm's stage-i input digest must
  equal the agent's own stage-(i−1) output digest; the carry-reference
  arm's must equal the frozen reference. Chain-breaking and arm-collapse
  mutants (M10, M12) die.
- **Verification vs RunFailure**: case timeouts and wrong exit codes are
  behavior; spawn faults, agent faults, and budget faults are
  infrastructure. A failing verdict never halts a family; a missing
  workspace censors exactly the recorded suffix (M08, M11 die).
- **Authority separation**: sealed cases live in the family record only;
  `CheckpointDelivery` is structurally public-only; leakage is rejected
  at family construction and re-checked at admission for
  `model_construct`-bypassed inputs. The provider adapter renders from
  the contract and delivery alone, so sealed material cannot reach the
  prompt by construction.
- **Model-written code never touches the host**: the live screening
  branch constructs the container sandbox unconditionally — there is no
  host-execution fallback on that path (M15 dies) — and the sandbox's
  lockdown flags are pinned by tests (M16, M17 die). The host subprocess
  path survives only as `run_case_trusted` for reference builds and
  clearly marked fixture simulations.
- **Spend discipline**: live screening refuses to start without explicit
  approval and an under-cap estimate (M24 dies), refuses any stage call
  that could cross the cap mid-run, and meters every stage — failed
  stages included — into receipts (M21 dies).

## Task-family choice

A hand-verified seed family was chosen over synthesizing checkpointed
variants from an ingested source. GSM8K has no workspace/entrypoint
semantics to checkpoint, and decomposing a SWE-bench instance offline
would require inventing sealed suites that cannot be validated without
containers and paid calibration runs. Upstream hand-authored all 36 of
its problems, so a hand-verified family is the faithful minimal
instantiation; the agent-assisted synthesis pipeline (workflow S1–S6)
and its compute-priced gates (dual references, mutant/ambiguity,
churn-ratio, headroom) are the recorded next step. Full reasoning in
[NOTES.md](NOTES.md).

## Deferred, deliberately

- The `monolithic`, `foresight`, and `repair-scheduled` arms.
- Class B static-quality measurement, probe-based quality, and any
  report/estimand module for CE (the EI report is EI-shaped; CE's
  stage-indexed and slope estimands deserve their own preregistered
  design).
- Workflow stages S1–S6 (agent-assisted family synthesis) and gates
  G3/G4/G6.
- Resumable partial evidence for the live run: `run_ce_experiment`
  writes atomically at completion, which is proportionate at the
  preregistered ~$0.50 scale; the EI screening's append-and-resume
  discipline is the model if CE runs ever grow past trivial re-run
  cost.

## Claim limits

- All runs use scripted agents or a scripted gateway transport. Nothing
  here is evidence about real agent behavior under checkpoint
  evolution.
- The seed family's design pressure is asserted by construction
  reasoning, not measured by the churn-ratio gate (G4), which is not
  implemented.
- Admission relies on a single incremental reference; the
  dual-reference ambiguity regimen is deferred with the synthesis
  pipeline.
