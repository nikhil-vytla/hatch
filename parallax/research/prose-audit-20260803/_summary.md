An unslop pass over all 45 markdown files under `parallax/` removed 396 em dashes and the surrounding ceremony, but the useful output was structural. Findings had no index, so answering "what has this project learned" meant opening a dated folder and reading a chronology; `docs/FINDINGS.md` is now one table of every run that spent money, what it asked, what came back, and what it cost. Four READMEs certified mutation-testing kill rates ("28/28", "49/49") from gauntlets that were never committed, and the reported denominator drifts between folders, so those are marked unreproducible. Six stale claims were corrected, the largest being a method doc asserting "no real-model evidence exists" after a \$0.28 paid run had already landed. A reusable [`check_markdown.py`](check_markdown.py) now fails on broken relative links, missing heading anchors, and pre-[PR #26](https://github.com/nikhil-vytla/hatch/pull/26) LaTeX delimiters, one of which had survived the math conversion.

- Money and math collide on GitHub: `(\$0.1721 vs \$0.1092)` renders as LaTeX, so every `$` followed by a digit is escaped across 23 files.
- Writing the findings index honestly exposed that no flow has both a complete design and evidence at a resolving scale, which was easy to miss while it was spread across four folders.
- Prose describing the decision gate was flagged rather than polished while [PR #30](https://github.com/nikhil-vytla/hatch/pull/30) was open, then deleted once #30 merged. Intervals and minimum detectable effects stayed, since those are measurements; the advance/reject verdicts computed against them named a procedure that no longer exists.
