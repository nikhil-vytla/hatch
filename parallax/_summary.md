Parallax implements offline [Evolving Intent](https://arxiv.org/abs/2607.20734v1) paths for GSM8K and SWE-bench Verified using strict frozen Pydantic models, sealed verifiers, canonical evidence, and source-clustered reporting. The SWE path pins the paper's published source IDs, holds the gold patch under sealed authority, gives every arm one equal episode budget, delivers scripted turns from the evaluation loop rather than an agent-callable tool, and grades candidate patches with the pinned official [SWE-bench](https://github.com/SWE-bench/SWE-bench) harness in a separate digest-pinned image. Two screening rounds and one preregistered 18-unit static-versus-evolved experiment have run against Claude Opus 4.8 for $5.86 metered; the experiment's paired delta is +0.111 with an interval spanning the whole estimand, so it settles nothing about intent evolution. GSM8K has all three arms and has never called a real provider, while SWE-bench has real episodes and no matched control, which is the gap the next run has to close. Parallax follows the semantics of the immutable [Microsoft reference revision](https://github.com/microsoft/evolving-intent/tree/993d6be9597ac03854b46362ccd647eb1bfd267a) without claiming provider-text parity, generated-pool reproduction, or paper-score reproduction.
