Parallax defines a research model for controlled perturbations of agent tasks and environments, with explicit public inputs, sealed evaluator authority, admission invariants, matched arms, and estimands. [Evolving Intent](https://arxiv.org/abs/2607.20734v1) is documented as one synthesis strategy that changes an interaction trajectory while preserving the source verifier and terminal task. Implementation guidance points to an immutable [Microsoft reference revision](https://github.com/microsoft/evolving-intent/tree/993d6be9597ac03854b46362ccd647eb1bfd267a), while Parallax remains an independent implementation with no dependency on that repository. Executable synthesis, behavioral regression tests, and experiment execution are not present, and no generated-data, byte-level, or paper-score reproduction is claimed.
