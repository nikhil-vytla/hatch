# tally

Invoices, VAT and currency conversion for small businesses.

- `tally/`: the library: money, invoices, VAT, FX, customers, payments, and
  `tally.export`, the rows for the data warehouse.
- `tally_api/`: the JSON the web app reads.

Python 3.11 or later, standard library only. `./dev help` lists the
development tasks.
