strive is being rebuilt from a Python research kernel into a coding agent you can install and start in any repository with no config file. Its differentiator is self-improvement you can trust: learned memory and skill changes are gated and reviewable. A per-user Rust daemon owns the trusted parts: the journal, budgets, model gateway, sandboxed effects and checkpoints. The agent loop (on [pi-mono](https://github.com/badlogic/pi-mono)), a pi-tui terminal client and an Electron desktop app all talk to it over JSON-RPC generated from one Rust declaration. Milestone M0 ships the daemon lifecycle, protocol codegen with a drift check, the TUI shell, `strive doctor` and an installer, with a warm launch to first TUI frame of about 59 ms.

- A UI spike chose Electron: it held 120 fps while streaming. Tauri was capped at 60 fps, and GPUI collapsed to 24–30 fps from frame pacing.
- ADR-0015 records the rebuild. The Python implementation is at git tag `strive-py-final`.
