strive, rebuilt from a Python research kernel, is now a coding agent you install once and start in any repository with no config file, from a terminal UI, an Electron desktop app, or headless with `strive run`. A per-user Rust daemon owns everything that must be trusted: the authenticated session journal, integer-dollar budgets enforced before each model call, the model gateway, sandboxed file and command effects (Seatbelt on macOS, bubblewrap plus seccomp on Linux), git checkpoints with rewind, and MCP servers run as gated, cancellable effects. The agent loop runs on [pi-mono](https://github.com/badlogic/pi-mono) in a host that holds no keys and touches no files, and every client speaks one JSON-RPC protocol generated from Rust types. Five rounds of adversarial Codex review drove most of the hardening: each round's findings were fixed test-first, and a test that could not fail was treated as a bug. Through a [Harbor](https://github.com/harbor-framework/harbor) adapter, Claude Haiku 4.5 on strive solved Terminal-Bench 2.0's `fix-git` for $0.036.

- The UI spike chose Electron: it held 120 fps while streaming, where Tauri was capped at 60 and GPUI collapsed to 24–30.
- The reviews found real escapes: symlink swaps between gate and write, seccomp bypasses (inherited filter pipes, io_uring, datagram socketpairs, x32), a desktop window able to act on other sessions, agent widgets reaching the network over WebRTC, approvals stranded when their approver left, and MCP servers left working after a cancelled call.
- Real-model checks: an M4 daily-use run on this repo cost $0.0069, and Harbor's hello-world scored 1.0 for $0.0035.
