Strive is a new self-evolving agent harness whose first vertical slice runs the full loop — execute → observe → evaluate → diagnose → propose → validate → accept/reject → retain — over executable strategy code rather than prompts. A deliberately naive seed strategy fails negative-integer cases; the harness diagnoses the weakness purely from trace evidence, applies a bounded code patch, validates the candidate in an isolated subprocess with a hard timeout, and accepts it (score 0.571 → 1.000, zero regressions) into an append-only ledger with full lineage. Because the active generation is derived from the journal, restart persistence and durable rollback come for free, as demonstrated in the committed demo transcript. The typed Python project ([strive/](.)) is built with [uv](https://docs.astral.sh/uv/) and pytest, passes 23 offline tests and strict mypy, and its charter maps six maturity stages toward model-in-the-loop proposals and real sandboxing.

- Evolvable surface is real code: strategies are standalone Python files run out-of-process (`python -I` + timeout); hangs, crashes, and bad outputs are contained and recorded.
- Explicit acceptance rules: strict score improvement AND no regressions; every candidate — accepted or rejected — is retained with parent, weakness, decision, and reason.
- Diagnosis abstains honestly: failures that don't match a known trace signature yield no proposal instead of a guess.
