# Milestone 8 live tau2 fixes

Adapter fixes are implemented for the three captured failures. Full-inventory certification still has an independent, pre-existing split-overlap blocker. No task, assertion, group rule, split, or live test gate was removed. The orchestrator must rebuild and run tau2 in Linux to establish the live results.

1. Certification applied reference actions with `make_tool_call()` and then asserted on that unsynchronized DB target. The captured report contains 192 mobile-data, 1,488 MMS, and eight service assertion failures. Qualification now records the reference actions through `get_response()`, preserving synchronization after each call, and passes the complete trajectory, including initial history, to `EnvironmentEvaluator.calculate_reward(..., strict_replay=True)`. Every assertion must pass; tool errors and a failing selected environment reward still block with task IDs. The separate strict check of raw gold actions remains. Upstream checks assertions on the replayed predicted environment; its raw gold environment supplies the DB comparison target. See [EnvironmentEvaluator.calculate_reward](https://github.com/sierra-research/tau2-bench/blob/a2c024725189473d2d7cea3a5cfdbcc67478e41f/src/tau2/evaluator/evaluator_env.py#L20) and [Environment.get_response](https://github.com/sierra-research/tau2-bench/blob/a2c024725189473d2d7cea3a5cfdbcc67478e41f/src/tau2/environment/environment.py#L431).

2. The equivalence traceback actually stops before reward comparison. `UserState.flip_roles()` rebuilds messages with fresh timestamps, so two captures of the same model request compare unequal. Request capture now omits only the top-level message timestamp. Content, roles, tool IDs, tool arguments, schemas, model and settings remain bound, including a tool argument named `timestamp`. Upstream's [to_litellm_messages](https://github.com/sierra-research/tau2-bench/blob/a2c024725189473d2d7cea3a5cfdbcc67478e41f/src/tau2/utils/llm_utils.py#L157) also excludes this metadata. Scoring now calls the pinned deterministic component evaluators and combines their rewards as [evaluate_simulation with EvaluationType.ALL](https://github.com/sierra-research/tau2-bench/blob/a2c024725189473d2d7cea3a5cfdbcc67478e41f/src/tau2/evaluator/evaluator.py#L181) does. This handles absent versus empty environment criteria, executes all assertions, preserves premature-stop zero rewards, and runs no NL grader. [CommunicateEvaluator.evaluate_communicate_info](https://github.com/sierra-research/tau2-bench/blob/a2c024725189473d2d7cea3a5cfdbcc67478e41f/src/tau2/evaluator/evaluator_communicate.py#L45) retains case-insensitive substring matching and removes commas from assistant text. [ActionEvaluator.evaluate_actions](https://github.com/sierra-research/tau2-bench/blob/a2c024725189473d2d7cea3a5cfdbcc67478e41f/src/tau2/evaluator/evaluator_action.py#L122) retains membership matching through `Action.compare_with_tool_call`. The live oracle now invokes the full `evaluate_simulation()` entry point and checks 19 cases.
